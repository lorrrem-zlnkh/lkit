# Lkit — правила проекта

Каталог инструментов для дизайнеров и русскоязычный IT-словарь: статика в `site/`, сборщики в `scripts/`.

## Аналитика правится тем же коммитом

**Изменение, которое меняет устройство, экран, данные или выкладку, правит аналитику в том же коммите** — `Memory/lkit-analytics.md`.

Машинный слой (блоки `auto:`) пересобирает хук сам, руками внутри них не правят. До 1 октября 2026 документ отставал на три с половиной месяца и 21 коммит — поэтому обновление теперь в хуке.

Хуки ставит общий скрипт: `python3 ~/Documents/Lorrrem-projects-memory/tools/sync-analytics.py --install-hooks`.

## README — копия аналитики

`README.md` собирается хуком из `Memory/lkit-analytics.md` (`cp` в `post-commit`). Править README руками бессмысленно: следующий коммит его перезапишет. Нужно другое содержание в README — меняется хук, а не файл.

## Словарь

Номер термина идёт в сообщении коммита — «Add Оверхед to dictionary (807)»: счёт ведётся в истории, и пропуск номера потом не восстановить.

У термина, пришедшего из внешнего источника, в определении стоит ссылка на него. Определение своими словами без источника — слабее: проверить его нельзя, а словарём пользуются как доводом в споре.
